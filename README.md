# Blender Playground

Blender experiments, built mostly from headless Python scripts (Blender 5.2).

| Project | What it is |
|---|---|
| [janiecooper/](janiecooper/) | Janie & Cooper (our English bulldog) walking in Niguel Heights Park at golden hour: park from OpenStreetMap data, stylised bulldog, MPFB character, procedural animation |
| [cooper-game/](cooper-game/) | Cooper's Park Run: a small Godot 4.7 game using those assets. Play as Cooper and push the beach ball back to Janie. Assets come from `janiecooper/export_game_assets.py`; run `play.bat` |
